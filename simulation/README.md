# Simulation

The current repository documents the experimentally built hardware prototype.

A simulation model can be added here later to compare:

- ideal CCM boost behavior
- 33 µH inductor ripple
- 50 kHz switching
- 20 Ω load
- 6 V input
- approximately 50% duty ratio
- synchronous MOSFET operation

Recommended future comparison plots:

1. \(V_{in}\) vs \(V_o\)
2. Duty ratio vs \(V_o\)
3. Inductor current
4. MOSFET gate signals
5. Switching-node voltage
6. Output ripple
7. Simulated vs measured output voltage
